Install Tailscale + android-sms-gateway on old Android. Insert cheap T-Mobile MVNO SIM (Ultra Mobile $3/mo or Mint). Enable WiFi Calling in carrier settings. Disable battery optimization for gateway app. Set USB mode to Charging Only. Plug into machine.
